# 06 知识蒸馏参数研究实验

## 实验目的

研究不同的知识蒸馏参数（温度 T 和 alpha α）对知识迁移效果的影响。

## 实验场景

- **4个大数据节点**（性能有限）：每个节点有大量数据
- **1个小数据节点**（性能很好）：数据量只有大数据节点的1/10

## 参数设置

### Temperature (T)
- 范围：[1, 2, 3, 4, 5, 6, 8, 10]
- 作用：控制软标签的"软化"程度，T越大，概率分布越平滑

### Alpha (α)
- 范围：[0.1, 0.3, 0.5, 0.7, 0.9]
- 作用：平衡蒸馏损失和交叉熵损失的权重
  - α=1.0: 完全使用蒸馏损失
  - α=0.0: 完全使用交叉熵损失（标准训练）

## 实验流程

1. **训练教师模型**
   - 4个大数据节点进行联邦平均(FedAvg)训练
   - 训练参数：10轮通信，每轮5个本地epoch

2. **参数网格搜索**
   - 对每组(T, α)参数：
     - 使用教师模型对小数据节点进行知识蒸馏
     - 训练100个epoch
     - 记录最佳测试准确率

3. **对比实验**
   - 基线：小数据节点独立训练（不使用KD）
   - 教师：FedAvg聚合模型
   - 学生：使用不同KD参数训练的模型

## 实验意义

通过系统地研究KD参数的影响，我们可以：

1. **找到最优参数组合**：确定在联邦学习场景下最有效的T和α值
2. **理解参数作用机制**：
   - Temperature如何影响知识的"软化"程度
   - Alpha如何平衡教师知识和真实标签
3. **指导实际应用**：为不同场景下的KD应用提供参数选择建议

## 预期结果

- 学生模型性能应优于基线模型
- 存在最优的(T, α)组合使性能最大化
- 过大或过小的T和α可能导致性能下降

## 与05实验的区别

- **05实验**：循环知识迁移，固定KD参数(T=4, α=0.7)
- **06实验**：系统研究KD参数空间，寻找最优配置
