# 知识迁移实验 (Knowledge Transfer Experiment)

## 实验场景

模拟一个真实的联邦学习场景：
- **4个大数据节点**: 拥有大量数据，但计算性能有限
- **1个小数据节点**: 计算性能强大，但数据量很少（只有大数据节点的1/10）

## 实验目标

通过知识蒸馏技术，让性能强大的小数据节点能够从大数据节点的联邦模型中学习知识，然后将训练好的模型返回给大数据节点继续使用，从而提升整体系统性能。

## 三阶段实验流程

### 阶段1: 初始联邦平均训练 (4个大数据节点)
1. 4个大数据节点各自在本地数据上训练
2. 每个通信轮次包含多个本地训练epoch
3. 完成本地训练后进行联邦平均(FedAvg)聚合
4. 聚合后的模型同步到所有节点
5. 得到聚合后的**教师模型**

**默认配置**: 25个通信轮次 × 5个本地epochs = 125个总训练epochs

### 阶段2: 知识蒸馏训练 (1个小数据节点)
1. 使用阶段1的教师模型作为知识源
2. 小数据节点作为学生模型
3. 在小数据节点的有限数据上进行知识蒸馏训练
4. 学生模型同时学习：
   - 教师模型的软标签（知识蒸馏）
   - 真实标签（标准训练）
5. 得到训练好的**学生模型**

**默认配置**: 100个epochs的知识蒸馏训练

### 阶段3: 返回联邦训练 (4个大数据节点 + 学生模型)
1. 将阶段2训练好的学生模型返回给4个大数据节点
2. 所有节点使用学生模型参数作为初始化
3. 继续进行联邦平均训练
4. 验证学生模型能否帮助大数据节点达到更好的性能

**默认配置**: 25个通信轮次 × 5个本地epochs = 125个总训练epochs

### 基线对比
实验包含两个基线对比：
1. **基线1**: 完整的联邦平均训练（50轮，不使用知识蒸馏）
2. **基线2**: 小数据节点独立训练（100 epochs，不使用知识蒸馏）
1. 使用阶段1的聚合模型作为教师模型
2. 小数据节点作为学生模型
3. 在小数据节点的有限数据上进行知识蒸馏训练
4. 学生模型同时学习：
   - 教师模型的软标签（知识蒸馏）
   - 真实标签（标准训练）

### 基线对比
同时训练一个基线模型：小数据节点独立训练（不使用知识蒸馏），用于对比知识蒸馏的效果。

## 数据分配

默认配置：
- **总训练样本**: 50,000
- **每个大数据节点**: ~12,195 样本
- **小数据节点**: ~1,219 样本
- **数据比例**: 10:1

## 训练配置

### 阶段1: 初始联邦训练
- **通信轮次**: 25轮
- **每轮本地训练**: 5个epochs
- **总训练量**: 25 × 5 = 125 epochs
- **参与节点**: 4个大数据节点

### 阶段2: 知识蒸馏
- **训练epochs**: 100
- **知识源**: 阶段1的教师模型
- **训练节点**: 1个小数据节点
- **蒸馏参数**: T=4.0, α=0.7

### 阶段3: 返回联邦训练
- **通信轮次**: 25轮
- **每轮本地训练**: 5个epochs
- **总训练量**: 25 × 5 = 125 epochs
- **初始化**: 使用阶段2的学生模型
- **参与节点**: 4个大数据节点

### 基线配置
- **基线1**: 完整FedAvg (50轮 × 5 epochs = 250 epochs)
- **基线2**: 小数据独立训练 (100 epochs)

## 实验参数

可以在代码中调整的参数：

### 联邦学习参数
| 参数 | 默认值 | 说明 |
|------|--------|------|
| `num_large_nodes` | 4 | 大数据节点数量 |
| `phase1_rounds` | 25 | 阶段1的通信轮次数 |
| `phase2_rounds` | 25 | 阶段3的通信轮次数 |
| `local_epochs` | 5 | 每轮的本地训练epoch数 |
| `large_to_small_ratio` | 10 | 大小节点数据量比例 |

### 训练参数
| 参数 | 默认值 | 说明 |
|------|--------|------|
| `student_epochs` | 100 | 阶段2学生模型的训练epoch数 |
| `lr` | 0.1 | 学习率 |
| `batch_size` | 128 | 批次大小 |

### 知识蒸馏参数
| 参数 | 默认值 | 说明 |
|------|--------|------|
| `temperature` | 4.0 | 蒸馏温度 |
| `alpha` | 0.7 | 蒸馏损失权重 |
| `seed` | 42 | 随机种子 |

实验将输出：
1. **阶段1 - 教师模型准确率**: 初始联邦平均后的性能

3. **阶段3 - 最终模型准确率**: 使用学生模型继续联邦训练后的性能

5. **基线2准确率**: 小数据节点独立训练的性能
6. **改进幅度**: 
   - 学生模型 vs 小数据基线
   - 最终模型 vs FedAvg基线

## 关键发现

通过这个三阶段实验，我们可以验证：
1. **知识蒸馏的有效性**: 小数据节点能否从大数据节点学到知识
2. **知识回传的价值**: 训练好的学生模型返回给大数据节点后，能否提升整体性能
3. **数据不平衡场景**: 在数据量相差10倍的情况下，知识蒸馏和迁移的效果
4. **联邦学习+知识蒸馏组合**: 两种技术结合的实际应用价值

可视化图表帮助我们直观地观察：
- 三个阶段的性能演变
- 知识蒸馏如何帮助小数据节点
- 学生模型返回后的性能提升
- 与完整FedAvg基线的对比

## 应用场景

这种三阶段知识迁移场景在实际中很常见：
- **边缘-云协作**: 边缘设备（数据多但算力弱）+ 云端服务器（数据少但算力强）
  - 边缘设备先联邦训练得到基础模型
  - 云端服务器用少量数据进行知识蒸馏优化
  - 优化后的模型返回给边缘设备继续训练
  
- **移动设备-中心服务器**: 移动设备（数据多）+ 中心服务器（数据少但性能好）
  - 移动设备收集大量用户数据并联邦训练
  - 中心服务器用精选数据进行蒸馏优化
  - 优化模型下发给所有移动设备
  
- **IoT-边缘节点**: IoT设备集群（数据多）+ 边缘计算节点（数据少但性能好）
  - IoT设备联邦训练基础模型
  - 边缘节点快速蒸馏优化
  - 优化模型返回IoT设备提升性能
